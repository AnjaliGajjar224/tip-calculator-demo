# Tip calculator

Open `index.html` in a browser or an HTML preview. All CSS and JavaScript are included in this one file, so previews do not need to load sibling assets. JavaScript must be enabled by the preview host.

Enter a bill amount in US dollars and select 10%, 15%, or 20% (15% is selected initially). Results update immediately. The calculator rounds the bill and tip to whole cents, then adds them for the final total. Negative or unsupported amounts show an error.

The page contains three beginner-friendly sections: CSS in the head, HTML controls, and JavaScript after the controls. The `calculateTip` function does the math; `updateResults` reads the input and updates the displays. Button listeners select a percentage and recalculate.

Run calculation tests with Node.js, without installing any packages:

```sh
node calculator.test.js
```

The tests read the calculation script directly from `index.html`, so they exercise the same function as the website.

To serve the page locally, run `python3 -m http.server 8000` from this directory. If a preview shows “An error occurred inside the visualization,” check whether its host allows JavaScript. That message is not generated by this application.
